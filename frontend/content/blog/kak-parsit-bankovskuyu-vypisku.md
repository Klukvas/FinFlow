# Как парсить банковскую выписку PDF: автоматизация учёта транзакций

Ручной ввод каждой транзакции из банковской выписки — это трата времени и источник ошибок. В этой статье мы разберём, как автоматически извлекать данные из PDF-выписок украинских банков и превращать их в структурированные записи.

## Зачем парсить выписки?

Большинство банков позволяют скачать выписку в формате PDF. Проблема в том, что PDF — это формат для **отображения**, а не для **данных**. Таблицы внутри PDF не имеют чёткой структуры: координаты текста могут «плавать», форматирование отличается от банка к банку.

Автоматический парсинг решает несколько задач:

- **Экономия времени** — вместо 30-60 минут ручного ввода, данные загружаются за секунды
- **Точность** — исключаются ошибки при ручном вводе сумм и дат
- **Категоризация** — MCC-коды позволяют автоматически определить тип траты

## Форматы выписок украинских банков

### Monobank

Monobank формирует выписки в характерном формате с колонками:

| Поле | Описание |
|------|----------|
| Дата | Дата и время транзакции |
| Описание | Название получателя / торговой точки |
| MCC | Код категории торговца |
| Сумма | Сумма в валюте карты |
| Комиссия | Комиссия банка (если есть) |
| Кешбэк | Начисленный кешбэк |

### ПриватБанк

ПриватБанк использует другой формат, с отдельными полями для операций списания и зачисления. Ключевые поля:

- Дата операции и дата списания
- Описание операции
- Сумма в валюте карты и валюте операции
- Остаток после операции

## Что такое MCC-коды и как их использовать

**MCC (Merchant Category Code)** — четырёхзначный код, который присваивается каждому торговцу при регистрации терминала. Этот код указывает на тип бизнеса:

- `5411` — Супермаркеты и продуктовые магазины
- `5812` — Рестораны и кафе
- `5541` — Автозаправочные станции
- `4121` — Такси и лимузины
- `5977` — Косметика и парфюмерия

Используя MCC-коды, можно автоматически присваивать категорию каждой транзакции без ручной работы. FinFlow поддерживает маппинг MCC-кодов на пользовательские категории — достаточно один раз настроить соответствие.

## Практический подход к парсингу

### 1. Извлечение текста из PDF

Первый шаг — получить сырой текст из документа. Библиотеки вроде `pdfplumber` (Python) или `pdf.js` (JavaScript) позволяют извлекать текстовые слои с координатами.

```
PDF файл → Извлечение текстового слоя → Сырой текст с координатами
```

### 2. Определение банка

По структуре документа (заголовки, расположение колонок) определяется банк-эмитент. Это важно, потому что формат таблицы отличается.

### 3. Парсинг таблицы транзакций

Каждая строка таблицы разбирается на компоненты: дата, описание, сумма, MCC-код. На этом этапе обрабатываются:

- Многострочные описания
- Суммы с разными разделителями (точка, запятая, пробел)
- Конвертация валют
- Операции возврата (отрицательные суммы)

### 4. Категоризация по MCC

Извлечённый MCC-код сопоставляется с таблицей категорий. Если MCC-код не найден, транзакция помечается как «без категории» для ручной классификации.

## Как это работает в FinFlow

В FinFlow весь процесс автоматизирован:

1. Загрузите PDF-выписку в раздел **PDF Парсер**
2. Система определит банк и извлечёт транзакции
3. Каждая транзакция автоматически получит категорию на основе MCC-кода
4. Просмотрите результат и подтвердите импорт

Поддерживаются выписки **Monobank** и **ПриватБанк**. Парсинг работает полностью на стороне сервера — ваши файлы обрабатываются в защищённой среде и не сохраняются после обработки.

## Советы по работе с выписками

- **Скачивайте выписки регулярно** — раз в неделю или месяц. Так проще отслеживать расходы
- **Проверяйте результат парсинга** — автоматика точна, но ошибки в исходном PDF случаются
- **Настройте маппинг MCC** — потратьте 10 минут на начальную настройку, и категоризация будет работать автоматически
- **Используйте теги** — для дополнительной классификации помимо категорий

## Заключение

Автоматический парсинг банковских выписок экономит часы работы и делает учёт финансов точнее. Вместо того чтобы вручную вводить каждую покупку, достаточно загрузить PDF — и все транзакции будут распарсены, категоризированы и готовы к анализу.
