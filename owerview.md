# FinFlow — Overview для дизайнера

## Что это

**FinFlow** — SaaS-платформа для управления личными финансами. Веб-приложение (PWA), работает на десктопе и мобильных устройствах через браузер. Целевая аудитория — пользователи из Украины и СНГ, которые хотят контролировать свои расходы, доходы, долги и финансовые цели.

**Языки интерфейса:** английский, русский, украинский.
**Темы:** светлая, тёмная, автоопределение по системе.

---

## Бизнес-модель

Freemium-подписка через Paddle Billing:

| План | Цена | Ключевые ограничения |
|------|------|---------------------|
| **Free** | $0 | Базовые лимиты по категориям, целям, без AI |
| **Basic** | $4.99/мес | Расширенные лимиты |
| **Professional** | $9.99/мес | 100+ категорий, AI-ассистент (5 запросов/мес) |
| **Enterprise** | Индивидуально | Без лимитов, AI (15 запросов/мес) |

Гейтинг фич (Pro-features) отображается по всему приложению — пользователь видит что доступно на более высоком плане.

## Детальное описание фич

### 1. Дашборд

Главный экран после входа. Содержит:

- **KPI-полоса** — ключевые показатели за выбранный период (1–12 месяцев)
- **Графики:**
  - Денежный поток (cash flow)
  - Сравнение месяцев
  - Расходы по категориям (круговая диаграмма)
  - Доходы по категориям (круговая диаграмма)
  - Топ расходов
  - Ежедневные траты
- **Виджеты-карточки:**
  - Балансы счетов
  - Обзор долгов
  - Повторяющиеся платежи
  - Прогресс целей
  - Прогресс бюджета
  - Предстоящие платежи
  - AI-инсайты (Pro)

### 2. Счета (Accounts)

Управление финансовыми счетами пользователя:

- Создание / редактирование / архивация счетов
- Поддержка мультивалютности (USD, EUR, UAH, и т.д.)
- Отображение баланса по каждому счёту
- Боковая панель с детальной историей транзакций по счёту
- Статистика по счёту
- Фильтрация и пагинация
- Экспорт в CSV

### 3. Расходы (Expenses)

Полный трекинг расходов:

- Создание / редактирование / удаление расходов
- Привязка к категории и счёту
- Мультивалютность
- Фильтры: диапазон дат, категория, счёт
- Полоса итогов — суммы по валютам
- Пагинация (клиентская + серверная)
- Экспорт в CSV

### 4. Доходы (Income)

Аналогично расходам:

- CRUD операции
- Привязка к категории и счёту
- Дашборд-вид (графики, статистика) и табличный вид
- Фильтры: даты, категория, счёт
- Полоса итогов
- Экспорт в CSV

### 5. Категории (Categories)

Иерархическая система категоризации:

- Родительские и дочерние категории (до 2 уровней вложенности)
- Два режима просмотра: **дерево** и **таблица**
- Цвета категорий
- Статистика использования
- Боковая панель с аналитикой по категории
- Автоматическое создание категорий из MCC-кодов (при импорте из банка)
- Лимиты на количество категорий по тарифу
- Экспорт в CSV

### 6. Долги (Debts)

Трекинг займов и кредитов:

- **Вкладка "Долги"**: создание / редактирование / удаление долгов
  - Тип: "мне должны" / "я должен"
  - Сумма, процентная ставка, график
  - Привязка к контакту
  - Запись платежей по долгу
  - Боковая панель с историей платежей
- **Вкладка "Контакты"**: управление кредиторами/должниками
  - CRUD операции
  - Контакт нельзя удалить, если привязан к долгу
- Статистика
- Фильтрация и пагинация
- Экспорт в CSV

### 7. Повторяющиеся платежи (Recurring)

Автоматизация регулярных трат:

- Создание шаблонов повторяющихся платежей
- Расписание: ежедневно / еженедельно / ежемесячно / ежегодно
- Автоматическое создание транзакций (расход или доход) по расписанию
- Просмотр предстоящих исполнений
- История исполнений
- Привязка к категории и счёту
- Боковая панель с деталями
- Экспорт в CSV

### 8. Финансовые цели (Goals)

Постановка и отслеживание финансовых целей:

- Целевая сумма и дедлайн
- Этапы (milestones) внутри цели
- Прогресс-бар и визуальное отображение
- Модальное окно обновления прогресса
- Фильтры: статус, дедлайн
- Статистика
- Лимиты по тарифу
- Экспорт в CSV

### 9. Парсер банковских выписок (PDF Parser)

Импорт транзакций из PDF-файлов банков:

- Загрузка PDF-выписки
- **Поддерживаемые банки:** Monobank, ПриватБанк, Укрсиббанк, Райффайзен, OTP Bank
- AI-распознавание транзакций из PDF
- Автоматическая категоризация через MCC-коды
- Экран ревью: пользователь проверяет и подтверждает транзакции перед импортом
- Массовый импорт в расходы/доходы
- Прогресс-бар массовых операций
- Обработка ошибок (дубликаты, лимиты категорий)

### 10. AI-ассистент

Финансовая аналитика на основе Claude AI:

- **6 типов анализа:**
  - Анализ расходов
  - Анализ доходов
  - Анализ трендов
  - Рекомендации по экономии
  - Анализ долгов
  - Анализ прогресса целей
- Готовые промпты для запуска анализа
- Кэширование результатов
- Лимиты запросов по тарифу (Professional: 5/мес, Enterprise: 15/мес)
- Поддержка 3 языков
- Доступно только на Professional и Enterprise планах

### 11. Рабочие пространства (Workspaces)

Мультитенантность и совместная работа:

- Каждый пользователь получает **личное пространство** при регистрации
- Создание дополнительных пространств (например, семья, бизнес)
- Переключение между пространствами
- Приглашение участников по email
- **Роли:** Owner, Admin, Member, Viewer (read-only)
- Управление участниками (смена роли, удаление)
- Страница входящих приглашений (принять / отклонить)
- Личное пространство нельзя удалить

### 12. Профиль пользователя

Настройки аккаунта:

- Редактирование email
- Выбор базовой валюты
- Информация о текущей подписке и лимитах
- Перезапуск интерактивного туториала
- Просмотр использования (категории, цели, AI-запросы)

### 13. Система подписок и оплата

- Страница сравнения тарифов
- Оплата через Paddle Billing
- История платежей
- Гейтинг фич: пользователь видит заблокированные Pro-функции с предложением апгрейда
- Страницы помощи: условия подписки, политика возврата, отмена

### 14. Туториал для новых пользователей

- Интерактивный overlay-туториал при первом входе
- Пошаговое знакомство с основными функциями
- Возможность перезапуска из профиля
- Сохранение прогресса

## UI-паттерны, используемые в приложении

### Компоненты

- **Модальные окна** — для создания/редактирования сущностей (расход, доход, долг, цель, счёт и т.д.)
- **Боковые панели (Side panels)** — для детального просмотра (статистика счёта, история платежей долга, аналитика категории)
- **Карточки** — группировка контента (виджеты дашборда, планы подписки)
- **Таблицы** — основной способ отображения списков с сортировкой и пагинацией
- **Полоса итогов (Summary strip)** — компактное отображение ключевых сумм над таблицей
- **Фильтр-бар** — фильтрация по датам, категориям, счетам
- **Табы** — переключение режимов (таблица/график, долги/контакты)
- **Дерево** — иерархический просмотр категорий
- **Скелетоны** — загрузочные состояния
- **Тосты (Sonner)** — уведомления об успешных/ошибочных действиях
- **Бейджи и чипы** — статусы, теги
- **Графики** — pie, bar, line (библиотека визуализации)

### Формы

- Валидация полей с inline-ошибками
- Форматированный ввод чисел
- Селекторы категорий, валют, счетов
- Выбор дат

### Состояния

- Загрузка (скелетоны)
- Пустое состояние (empty state с пояснением)
- Ошибка (баннер + кнопка повтора)
- Error boundary (fallback UI)

## PWA

Приложение — Progressive Web App:

- Установка на рабочий стол (десктоп, iOS, Android)
- Standalone-режим (без адресной строки)
- Промо установки: кнопка в хедере + модальное окно после логина
- Определение платформы (iOS / Android / Desktop) для кастомных инструкций
- Сохранение состояния dismiss (не показывать повторно)
- Service Worker для кэширования
- Иконки 192px и 512px (maskable)
