# FinFlow Feature Roadmap

Конкурентный анализ и план развития продукта.
Последнее обновление: 2026-02-27

---

## Текущие сильные стороны

- Микросервисная архитектура (масштабируемость)
- PDF-парсер банковских выписок (Monobank, ПриватБанк) с MCC-автокатегоризацией
- Мультивалютность с автообновлением курсов
- Рабочие пространства с ролями (Owner / Full Access / Read-Only) и инвайтами
- Рекурринг-платежи (daily/weekly/monthly/yearly) с авто-созданием транзакций
- Финансовые цели с milestones и прогрессом
- Трекинг долгов с историей платежей и контактами
- 3 языка (en/ru/uk)
- Подписочная модель через Paddle (Basic / Professional / Enterprise)
- CSV-экспорт всех сущностей
- SEO-оптимизация: пререндеринг, sitemap, structured data, блог

---

## Высокий приоритет

Фичи, которые дают конкурентное преимущество и покрывают ожидания пользователей.

### 1. AI-ассистент для финансов

**Конкуренты:** Zen Money (GPT-powered)

**Что делает:**
- Пользователь задаёт вопросы на естественном языке: "сколько я потратил на такси в январе?"
- Система генерирует ответ + график/таблицу
- Анализ аномалий: "в этом месяце расходы на рестораны на 40% выше обычного"
- Рекомендации по оптимизации бюджета

**Почему у нас:**
- Все данные уже структурированы (транзакции, категории, MCC-коды)
- Нужно добавить LLM-слой поверх существующих API
- Максимальный wow-эффект при относительно невысокой сложности

**Оценка:** Высокая ценность / Средняя сложность

---

### 2. Автоматический импорт транзакций из банков (Bank Sync)

**Конкуренты:** Zen Money (3300+ банков), Wallet by BudgetBakers (15000+), YNAB (Plaid/MX/TrueLayer)

**Что делает:**
- Подключение банковского аккаунта через OAuth / Open API
- Автоматическое подтягивание транзакций (реалтайм или по расписанию)
- Авто-категоризация импортированных транзакций

**Подход для Украины:**
- Monobank Open API (публичный, с вебхуками)
- ПриватБанк API (ограниченный)
- Для глобального рынка: интеграция с Plaid / TrueLayer

**Почему у нас:**
- PDF-парсер — это полушаг к полной автоматизации
- Monobank API бесплатный и хорошо документирован
- Убирает главный friction — ручной ввод данных

**Оценка:** Высокая ценность / Высокая сложность

---

### 3. Прогноз кэшфлоу (Cashflow Forecasting)

**Конкуренты:** Wallet by BudgetBakers (7-дневный прогноз), Zen Money (AI-based)

**Что делает:**
- Показывает ожидаемый баланс на N дней вперёд
- Учитывает повторяющиеся платежи, зарплату, подписки
- Предупреждает о потенциальном дефиците: "через 12 дней баланс может стать отрицательным"

**Почему у нас:**
- Рекурринг-платежи уже есть — это входные данные для прогноза
- Можно начать с простой экстраполяции, потом добавить ML

**Оценка:** Высокая ценность / Средняя сложность

---

### 4. Система уведомлений (Push Notifications)

**Конкуренты:** Все (это table stakes)

**Что делает:**
- Превышение бюджетного лимита по категории
- Напоминание о предстоящем платеже
- Достижение финансовой цели
- Приближение к лимиту подписки
- Уведомление о новых транзакциях (при bank sync)

**Почему у нас:**
- У нас вообще нет уведомлений — это заметный пробел
- Email-уведомления как минимум, push через PWA как максимум

**Оценка:** Высокая ценность / Средняя сложность

## Средний приоритет

Фичи, которые значительно улучшают UX и расширяют аудиторию.

### 5. Dashboard с аналитикой (Net Worth + Overview)

**Конкуренты:** YNAB, Zen Money, Toshl

**Что делает:**
- Единый дашборд: баланс всех счетов, расходы/доходы за период, прогресс целей
- Net Worth = сумма всех счетов − сумма всех долгов
- Графики трендов: расходы по месяцам, доходы vs расходы
- Топ категорий расходов за период

**Оценка:** Высокая ценность / Средняя сложность

---

### 6. Сканирование чеков (OCR)

**Конкуренты:** Toshl, Splitwise

**Что делает:**
- Фото чека → распознание суммы, даты, магазина
- Создание транзакции из распознанных данных
- Хранение фото чеков привязанных к транзакциям

**Подход:**
- Google Vision API / Tesseract для OCR
- Или использование LLM для извлечения данных из текста чека

**Оценка:** Средняя ценность / Средняя сложность

---

### 7. Разделение расходов (Expense Splitting)

**Конкуренты:** Splitwise, Wallet (ShareCost), Money Lover

**Что делает:**
- Групповые расходы: "ужин на 4 человека, Андрей заплатил"
- Автоматический расчёт "кто кому сколько должен"
- Алгоритм минимизации количества переводов (как у Splitwise)
- Интеграция с существующей системой долгов

**Оценка:** Средняя ценность / Высокая сложность

---

### 8. Совместный бюджет (Family Budget)

**Конкуренты:** YNAB Together, CoinKeeper, Money Lover

**Что делает:**
- Воркспейс "Семья" с отдельными вкладами каждого участника
- Общие категории и бюджетные лимиты
- "Кто сколько потратил" внутри семейного бюджета
- Отдельные личные расходы внутри общего пространства

**Почему у нас:**
- Воркспейсы с ролями уже есть — нужен UX-слой поверх

**Оценка:** Средняя ценность / Средняя сложность

---

### 9. Трекинг инвестиций

**Конкуренты:** Zen Money, Mint/Credit Karma

**Что делает:**
- Учёт акций, крипто, ETF, депозитов
- Автоматическое обновление стоимости
- Включение в общий Net Worth
- P&L по портфелю

**Оценка:** Средняя ценность / Высокая сложность

## Низкий приоритет (nice to have)

Фичи, которые приятны но не критичны для роста.

### 10. Режим путешествия (Travel Mode)

**Конкуренты:** Money Lover, Toshl

**Что делает:**
- Группировка всех расходов за поездку в "событие"
- Автоконвертация валют по курсу на дату покупки
- Итоги поездки: сколько потрачено по категориям

---

### 11. Мобильные виджеты

**Конкуренты:** Money Lover, CoinKeeper

**Что делает:**
- Виджет на домашнем экране: быстрый ввод расхода
- Отображение текущего баланса
- Требует мобильное приложение (React Native / PWA)

---

### 12. Геолокация расходов

**Конкуренты:** Toshl

**Что делает:**
- Привязка транзакций к местам на карте
- Аналитика "где я трачу больше всего"
- Предложение мест для будущих покупок

---

### 13. "Возраст денег" (Age of Money)

**Конкуренты:** YNAB

**Что делает:**
- Метрика: сколько дней деньги лежат до того как будут потрачены
- Показатель финансовой подушки безопасности
- Мотивация увеличивать "возраст" денег

---

### 14. Геймификация

**Конкуренты:** Monobank (кот), ПриватБанк (рейтинг цифровості)

**Что делает:**
- Ачивки за регулярный учёт
- Стрики: "30 дней подряд записываете расходы"
- Уровни и бейджи

---

### 15. Open API для разработчиков

**Конкуренты:** Monobank, Zen Money

**Что делает:**
- Публичный REST API для сторонних интеграций
- Вебхуки для реалтайм-нотификаций
- Экосистема расширений и плагинов

---

## Рекомендуемая последовательность реализации

```
Фаза 1 (quick wins):
  ├── Dashboard с аналитикой и Net Worth
  ├── Push/email уведомления
  └── Прогноз кэшфлоу (на основе рекуррингов)

Фаза 2 (конкурентное преимущество):
  ├── AI-ассистент (LLM поверх данных)
  └── Monobank API интеграция (bank sync)

Фаза 3 (расширение аудитории):
  ├── OCR чеков
  ├── Семейный бюджет (UX поверх воркспейсов)
  └── Разделение расходов

Фаза 4 (дифференциация):
  ├── Трекинг инвестиций
  ├── Open API
  └── Мобильное приложение (React Native)
```
